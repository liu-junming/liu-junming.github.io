# Junming Liu's Homepage

Source for my personal academic homepage, built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.

Based on the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template by Yi Ren (MIT License, see [LICENSE](LICENSE)).

## Local development

```bash
bundle install
./run_server.sh   # serves at http://127.0.0.1:4000
```

Homepage content lives in `_pages/about.md` and the sections under `_pages/includes/`.
